# 다른 AI에게 맡기는 설비 3D 모델 의뢰서

K-Factory Copilot의 3D 지도에 쓸 설비 모델을 다른 AI(또는 사람)에게 부탁할 때 그대로 복사해 쓰는 문서입니다. 아래 "의뢰문"을 붙여 넣고, "참고 표"를 함께 주면 됩니다.

## 먼저 정할 것 (의뢰 전에)

| 질문 | 권장 |
| --- | --- |
| 무엇을 받을까 | 설비별 **GLB 파일**(three.js에서 바로 열림). 원본 STEP이 있으면 같이 |
| 어디서 모양을 얻을까 | ① 제조사가 공개한 CAD(약관에 맞게 사용) ② 없으면 공개 치수·사진을 보고 직접 모델링한 **예시 모양** |
| 한 번에 몇 개 | **한 종류만 먼저**(ABB IRB 2600ID) 시험하고 되면 넓히기 |
| 절대 하지 말 것 | 제조사 도면·사진·로고를 그대로 복제, 라이선스를 모르는 파일 사용 |

## 의뢰문 (복사해서 사용)

```
당신은 공장 3D 모델링 담당입니다. 웹(three.js) 3D 공장 지도에 넣을 "{설비명}" 모델을 만들어 주세요.

[목적]
- 자동차 부품 생산 라인의 3D 지도에서 쓰는 설비 모델입니다. 가까이 봐도 실물처럼 보여야 하지만, 파일은 가벼워야 합니다.

[필수 사양]
- 결과물: GLB 한 개(+ 가능하면 원본 STEP/STL). 파일 크기는 5 MB 이하.
- 단위: 미터. 원점은 바닥 중앙, +Y가 위, 설비의 앞면이 +Z.
- 크기: 아래 "참고 표"의 외곽 치수(가로 w × 깊이 d × 높이 h)를 ±2% 안에서 지킬 것. 이 값은 제조사 공개 사양입니다.
- 움직이는 부분은 이름을 붙인 별도 노드로 분리할 것(예: 6축 로봇은 J1~J6 각 관절, 프레스는 ram, 레이저는 pallet/door). 회전축은 노드의 로컬 축에 맞출 것.
- 부품 이름은 영어 snake_case로, 재질은 PBR(금속성·거칠기)로 설정. 도장 색은 중립 회색/흰색으로 두고 색 코드는 코드에서 입히므로 베이스 컬러에 의미를 넣지 말 것.
- 메시: 삼각형 15만 개 이하, 보이지 않는 내부 부품은 제거, 같은 볼트·부품은 인스턴스로.

[모양의 근거 — 반드시 구분해서 기록]
- 모든 부품에 근거 등급을 붙여 주세요: "제조사 CAD" / "공개 규격에서 계산" / "추정(예시)".
- 제조사 CAD를 쓸 때는 어디서 받았는지(URL)와 이용 약관·라이선스 문구를 그대로 적어 주세요. 약관이 상업·비공개 웹앱 사용을 허용하는지 확인되지 않으면 쓰지 말고 알려 주세요.
- 제조사 도면, 사진, 로고, 상표 문양을 복제하지 말 것. 이름은 제품 설명용으로만 사용.
- 읽은 것과 추정한 것을 섞지 말고, 모르면 "모름"이라고 쓸 것. 지어낸 수치 금지.

[검증]
- 완성 후 아래를 직접 확인해서 보고: ① 크기가 표와 맞는지 ② 노드 이름과 회전축 ③ three.js 뷰어에서 정면·측면·위 3장 캡처 ④ 파일 크기와 삼각형 수.
- 문제가 보이면 고쳐서 다시 캡처한 뒤 결과를 보내 주세요.

[결과 보고 형식]
1. 파일 목록과 크기
2. 부품별 근거 표(이름 / 근거 등급 / 출처 URL / 약관 문구)
3. 확인하지 못한 것, 가정한 것
```

## 참고 표 (프로필 `contracts/examples/factory_profile.line_a.json` 기준)

근거 등급은 프로필의 `provenance`와 같습니다. 직접 확인 = 제조사 페이지 원문을 읽음, 보조 출처 = 판매처·집계 사이트·요약, 가정 = 우리가 정한 값.

| 설비 | 참고 제품 | 외곽 w × d × h (m) | 치수 근거 |
| --- | --- | --- | --- |
| 6축 로봇 | ABB IRB 2600ID-15/1.85 | 0.676 × 0.511 × 1.9 | 보조 출처(베이스는 공식 데이터시트 원문, 높이는 가정) |
| 레이저 절단기 | TRUMPF TruLaser 3030 fiber | 9.229 × 6.145 × 2.2 | 직접 확인 |
| 프레스 브레이크 | TRUMPF TruBend 5130 | 3.98 × 1.9 × 2.84 | 직접 확인 |
| 디버링 | ARKU EdgeBreaker 1000 | 2.1 × 2.6 × 2.1 | 직접 확인 |
| 세척·건조 | KSN Industri 400 WRD | 4.64 × 1.39 × 1.665 | 보조 출처 |
| 최종 검사 | ZEISS ScanBox 5110 (door) | 2.2 × 2.85 × 3.05 | 직접 확인 |
| 마킹 | TRUMPF TruMark Station 5000 | 0.86 × 1.31 × 2.0 | 직접 확인 |
| 용접 전원 | Lincoln Electric Power Wave R450 | 0.571 × 0.355 × 0.63 | 보조 출처 |

로봇의 관절 범위(공식 데이터시트 원문): J1 ±180°, J2 +155/−95°, J3 +75/−180°, J4 ±175°, J5 ±120°, J6 ±400°. 팔 마디 길이는 ID형 값이 공개되지 않아 표준 IRB 2600 값(하부 0.9 m, 전완 약 0.8 m, 어깨 오프셋 0.15 m)을 가정으로 쓰고 있습니다.

## 받은 뒤 우리가 할 일

1. 파일을 `frontend/web-admin/public/models/`에 두고 `MachineDetail`에서 GLB를 불러오는 경로를 추가합니다(없으면 지금 도형으로 대체).
2. 노드 이름으로 움직임(관절, 램, 팔레트)을 연결하고, 정면·측면·위 사진으로 위치와 크기를 맞춥니다.
3. 부품별 근거 표를 프로필의 `provenance`와 "예시 모양(가정)" 표시에 반영합니다.
4. 라이선스 문구를 `docs/`에 기록하고, 확인되지 않은 파일은 쓰지 않습니다.

## 어느 AI에게 맡길지

- **CAD를 직접 만드는 도구** (예: `earthtojake/text-to-cad`, MIT, STEP/GLB 출력): 말로 설명한 부품은 만들 수 있지만 실제 제품의 정확한 형상은 근거가 있어야 합니다. 결과는 "추정(예시)"로 표시합니다.
- **FORGE처럼 STEP를 읽는 도구**: 제조사 STEP가 있을 때 가장 좋습니다. 먼저 STEP를 GLB로 내보낼 수 있는지 확인하세요.
- **일반 대화형 AI**: 위 의뢰문으로 수집·정리·검증 보고까지는 맡길 수 있지만, 파일 다운로드와 약관 동의는 사용자가 직접 해야 합니다.
