## Files used (unmodified GLB)
- `robot-arm-a.glb` (robot arm, articulated nodes element-a..f, claw-a/b)
- `conveyor-long.glb` (2 x 1 conveyor segment)
- `machine-window.glb` (used as the cooler)

## Modified
- `Textures/colormap.png`: recolored from the kit palette to the K-Factory light theme
  (purple shades -> neutral whites/grays, orange stripes -> `--kf-primary` #176c5b).
  The GLB files reference this texture by relative path.
