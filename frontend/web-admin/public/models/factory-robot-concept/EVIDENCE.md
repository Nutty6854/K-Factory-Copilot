# Factory robot concept — 자체 외형 설계

Broad base; swept-back lower arm; continuous elbow/forearm shell; lateral maintenance covers; neutral finish. General industry features observed in ABB/Yaskawa references; no CAD parts imported or traced.

모든 형상과 치수는 자체 설정한 추정(예시). 기존 ABB 기반 시제품의 축간 치수와 외곽을 적용하지 않았다. 제조사 CAD 부품·도면·사진·로고를 복제하거나 탑재하지 않았다. ABB/Yaskawa 로컬 검사에서 관찰한 일반 특징(관절 커버, 정비 커버, 플랜지, 외부 서비스 케이블)을 참고했다. 독창성/법적 권리 검증은 수행하지 않았다.

## 파일 / 설정
GLB 1734428 bytes, 삼각형 30008개. 외곽 w/d/h 0.640000 × 1.103000 × 1.341000m. 단위 m, +Y 위, +Z 전면, 바닥판 중심 원점. 이 크기는 제조사 스펙이나 ±2% 인증 대상이 아니라 자체 설계의 결과이다. 검토 자세의 파생 STL이며 원본 제조사 STEP 없음.
